ZADANIE 41 – PIERWSZE URUCHOMIENIE PHPMYADMIN

Do tej pory dane w naszych programach przechowywaliśmy głównie w zmiennych.

Na przykład:

$imie = “Adam”;
$wiek = 18;

Po zakończeniu działania programu takie dane nie są zapisane na stałe.

Do przechowywania większej ilości danych możemy wykorzystać bazę danych.

W kolejnych zadaniach będziemy korzystać z:

MySQL

Do wygodnej obsługi bazy danych wykorzystamy:

phpMyAdmin

phpMyAdmin pozwala między innymi:

* tworzyć bazy danych,
* tworzyć tabele,
* dodawać dane,
* przeglądać dane,
* zmieniać dane,
* usuwać dane.

Uruchom phpMyAdmin.

Na razie niczego nie twórz.

Obejrzyj główne okno programu.

Zwróć uwagę na listę baz danych znajdującą się po lewej stronie.

Zapamiętaj:

BAZA DANYCH
może zawierać różne tabele.

TABELA
przechowuje dane.

KOLUMNA
określa rodzaj przechowywanych danych.

WIERSZ
to jeden zapisany rekord.

Przykładowa tabela uczniowie może wyglądać tak:

id | imie | nazwisko | wiek
1  | Adam | Kowalski | 18
2  | Anna | Nowak    | 17

Tutaj:

id, imie, nazwisko, wiek

to kolumny.

Natomiast:

1 | Adam | Kowalski | 18

to jeden rekord.

ZADANIE 43 – TWORZENIE PIERWSZEJ TABELI

Otwórz w phpMyAdmin bazę:

szkola

Utwórz w niej nową tabelę o nazwie:

uczniowie

Tabela powinna posiadać cztery kolumny.

Utwórz kolumny:

id
imie
nazwisko
wiek

Ustaw:

id – INT
imie – VARCHAR(50)
nazwisko – VARCHAR(50)
wiek – INT

Dla pola:

id

ustaw klucz główny:

PRIMARY

oraz włącz:

AUTO_INCREMENT

Zapisz tabelę.

Po zapisaniu sprawdź jej strukturę.

Powinny być widoczne cztery pola:

id
imie
nazwisko
wiek

CO OZNACZAJĄ TE USTAWIENIA?

INT

oznacza liczbę całkowitą.

Dlatego wykorzystujemy go dla:

id
wiek

VARCHAR(50)

pozwala przechowywać tekst o długości maksymalnie 50 znaków.

Dlatego wykorzystujemy go dla:

imie
nazwisko

AUTO_INCREMENT

powoduje automatyczne nadawanie kolejnych numerów:

1
2
3
4
…

Dzięki temu nie będziemy ręcznie wpisywać numeru id.

// DODATKOWO:
//
// To, co przed chwilą utworzyliśmy za pomocą phpMyAdmin,
// można również utworzyć poleceniem SQL:
//
// CREATE TABLE uczniowie (
//     id INT AUTO_INCREMENT PRIMARY KEY,
//     imie VARCHAR(50),
//     nazwisko VARCHAR(50),
//     wiek INT
// );
//
// CREATE TABLE oznacza:
// utwórz tabelę.
//
// uczniowie to nazwa tabeli.
//
// Na razie nie wpisuj tego polecenia.
// Tabelę utwórz za pomocą phpMyAdmin.

============================================================

ZADANIE 45 – PRZEGLĄDANIE I ZMIANA DANYCH W PHPMYADMIN

Otwórz tabelę:

uczniowie

Wyświetl zapisane w niej rekordy.

Odszukaj ucznia:

Adam Kowalski

Zmień jego wiek:

18

na:

19

Sprawdź, czy w tabeli pojawiła się nowa wartość.

// DODATKOWO:
//

//
//

//
// DELETE FROM uczniowie WHERE id=4;

// usuń.
//
// WHERE określa,
// który rekord ma zostać usunięty.

// Na razie wykonuj te operacje za pomocą phpMyAdmin.

ZADANIE 46 – PIERWSZE POŁĄCZENIE PHP Z BAZĄ

Do tej pory bazę danych obsługiwaliśmy bezpośrednio w phpMyAdmin.

Teraz spróbujemy połączyć z nią program napisany w PHP.

Utwórz plik:

index.php

Utwórz zmienną:

$polaczenie

i zapisz:

$polaczenie = mysqli_connect(“localhost”, “root”, “”, “szkola”);

Następnie sprawdź:

if ($polaczenie)

Jeżeli połączenie działa, wyświetl:

Połączono z bazą danych

W przeciwnym przypadku za pomocą:

else

wyświetl:

Błąd połączenia

WYJAŚNIENIE:

mysqli_connect()

służy do połączenia PHP z bazą danych.

localhost

oznacza serwer znajdujący się na naszym komputerze.

root

to nazwa użytkownika.

“”

w tym przypadku oznacza puste hasło.

szkola

to nazwa bazy, z którą chcemy się połączyć.

Na tym etapie program ma tylko połączyć się z bazą.

Nie pobieraj jeszcze żadnych danych.

ZADANIE 47 – PIERWSZE POBRANIE DANYCH Z BAZY

Wykorzystaj połączenie z poprzedniego zadania:

$polaczenie = mysqli_connect(“localhost”, “root”, “”, “szkola”);

Utwórz zmienną:

$sql

i zapisz:

$sql = “SELECT * FROM uczniowie”;

Następnie wykonaj zapytanie:

$wynik = mysqli_query($polaczenie, $sql);

Pobierz jeden rekord:

$wiersz = mysqli_fetch_assoc($wynik);

Wyświetl:

$wiersz[“imie”];

Uruchom stronę.

Powinno zostać wyświetlone imię pierwszego ucznia.

Następnie zamiast samego imienia wyświetl:

imie
nazwisko

Wykorzystaj echo oraz operator:

.

Na stronie powinno pojawić się na przykład:

Adam Kowalski

// SQL:
//
// SELECT * FROM uczniowie;
//
// SELECT oznacza:
// pobierz dane.
//
// * oznacza:
// wszystkie kolumny.
//
// FROM oznacza:
// z tabeli.
//
// uczniowie
// to nazwa naszej tabeli.
//
// Czyli:
//
// SELECT * FROM uczniowie
//
// oznacza:
//
// pobierz wszystkie dane

//
//
// mysqli_query()

// mysqli_fetch_assoc()

ZADANIE 48 – WYŚWIETLENIE WSZYSTKICH UCZNIÓW

W poprzednim zadaniu pobraliśmy tylko jeden rekord.

Teraz wyświetlimy wszystkie rekordy.

Wykonaj:

$sql = “SELECT * FROM uczniowie”;

Następnie:

$wynik = mysqli_query($polaczenie, $sql);

Wykorzystaj pętlę:

while

Przykład:

while ($wiersz = mysqli_fetch_assoc($wynik)) {

echo $wiersz["imie"];
echo "<br>";

}

Uruchom stronę.

Powinny pojawić się imiona wszystkich uczniów.

Następnie zmień program tak, aby wyświetlał:

imie
nazwisko
wiek

Przykład:

Adam Kowalski 19
Anna Nowak 17
Piotr Wiśniewski 19

// SQL nadal jest bardzo prosty:
//
// SELECT * FROM uczniowie;
//
// Pobieramy wszystkie dane z tabeli.
//
// Różnica znajduje się po stronie PHP.
//
// mysqli_fetch_assoc()
// pobiera jeden rekord.
//
// while powoduje,
// że pobieramy kolejne rekordy,
// aż nie będzie już żadnego.

ZADANIE 50 – DODAWANIE UCZNIA Z FORMULARZA

W tym zadaniu połączymy dwie rzeczy:

formularz HTML, który już znasz,

oraz:

bazę danych.

Utwórz formularz korzystający z:

method=“POST”

Dodaj trzy pola:

imie
nazwisko
wiek

Dodaj przycisk:

Dodaj

Po wysłaniu formularza sprawdź:

if ($_SERVER[“REQUEST_METHOD”] == “POST”)

Pobierz:

$_POST[“imie”]
$_POST[“nazwisko”]
$_POST[“wiek”]

Zapisz dane w zmiennych:

$imie
$nazwisko
$wiek

Następnie utwórz:

$sql = “INSERT INTO uczniowie (imie, nazwisko, wiek)
VALUES (’$imie’, ‘$nazwisko’, ‘$wiek’)”;

Wykonaj:

mysqli_query($polaczenie, $sql);

Po wykonaniu zapytania wyświetl:

Dodano ucznia

W formularzu wpisz na przykład:

Marek
Nowak
18

Kliknij:

Dodaj

Następnie otwórz phpMyAdmin.

Sprawdź, czy Marek został zapisany w tabeli:

uczniowie

// SQL:
//
// INSERT INTO uczniowie (imie, nazwisko, wiek)
// VALUES (’$imie’, ‘$nazwisko’, ‘$wiek’);

// $wiek
